# Smart POS Pro (my-shop-pos)

Smart POS Pro V7.00 — แอป POS แบบหน้าเดียว (Static HTML) สำหรับร้านค้าขนาดเล็ก/กลาง ภาษาไทย — เน้นการใช้งานบนแท็บเล็ต/มือถือ (PWA-friendly) รองรับการสแกนบาร์โค้ด, จัดการสต็อก, รับของ (PO), ลูกหนี้, สมุดรายรับ-รายจ่าย และรายงานภาษีเบื้องต้น

## จุดประสงค์
แอปนี้ออกแบบมาให้ใช้งานได้ทันทีจากไฟล์ `index.html` (offline-first) โดยเก็บข้อมูลหลักใน storage บนเครื่อง และมีตัวเลือกเชื่อมต่อกับ Supabase เพื่อซิงค์ข้อมูลแบบไม่บังคับ เหมาะสำหรับร้านค้าที่ต้องการระบบขายหน้าร้านแบบเรียบง่าย ใช้งานได้โดยไม่ต้องตั้งเซิร์ฟเวอร์

---

## ไฮไลท์ของฟีเจอร์
- หน้าขาย (Sale) — สแกนบาร์โค้ดหรือค้นหาสินค้า เลือกขนาด/หน่วย แก้ไขจำนวน และออกบิล
- สต็อก (Stock) — เพิ่ม/แก้ไขสินค้า, นำเข้ารูปเป็นชุด, นับสต็อกแบบหน้าร้าน, ตรวจหาสินค้าซ้ำ, ส่งออกเป็น Excel
- ใบสั่งซื้อ / รับของ (PO) — สร้างใบสั่ง, ตรวจรับตามบิล, แนบรูปใบส่งของ
- ลูกค้า & วางบิล — บันทึกข้อมูลลูกค้า/วางบิลเชื่อถือได้
- สมุดลิ้นชัก & รายจ่าย — เปิด/ปิดกะ บันทึกรายจ่ายและรายการเงินเข้า-ออก
- รายงาน & ภาษี — สรุปยอดขายรายวัน/รายปี, สมุดรับ-จ่ายสำหรับยื่นภาษี
- ฟังก์ชันภาพรวม: พิมพ์เอกสาร, แชร์เอกสาร, ดูประวัติการขาย, คืนสินค้า (refund)
- Offline-first: ใช้ localForage (IndexedDB) เพื่อเก็บข้อมูลท้องถิ่น และตัวเลือกซิงค์กับ Supabase (ไม่บังคับ)
- QR / Barcode: ใช้ html5-qrcode สำหรับสแกนจากกล้อง (มือถือ/แท็บเล็ต)

## โครงสร้างไฟล์ (top-level)
โปรเจกต์ตอนนี้เป็นแอปหน้าเดียว — ไฟล์สำคัญ:
- `index.html` — แอปทั้งหมด (UI + JS + CSS แบบ inline/รวมอยู่ในไฟล์นี้)

หมายเหตุ: ไม่มีโครงสร้างโฟลเดอร์แยกเป็นซอร์สโค้ดหลายไฟล์ในรีโปนี้ — การพัฒนา/บำรุงรักษาจะง่ายขึ้นหากแยกเป็นไฟล์ JS/CSS/HTML แยกกันในอนาคต

---

## เทคโนโลยีที่ใช้ (stack)
- ภาษา: HTML (single-file app) + JavaScript (inline)
- CSS: Tailwind CSS (ผ่าน CDN)
- ไลบรารีเด่น:
  - html5-qrcode — สแกน QR/barcode ด้วยกล้อง
  - localForage — storage แบบ offline (IndexedDB/LocalStorage fallback)
  - xlsx (SheetJS) — ส่งออก/นำเข้า Excel
  - Google Fonts (Sarabun)
- (ตัวเลือก) Supabase — ใช้สำหรับซิงค์ข้อมูลระหว่างอุปกรณ์ (ต้องตั้งค่าแยก)

## วิธีรัน (จากโคลนใหม่)
แอปเป็นไฟล์ HTML เดี่ยว จึงมีวิธีรันที่ง่าย:

1) เปิดโดยตรง (ไม่แนะนำเมื่อใช้กล้อง)
- ดับเบิลคลิก `index.html` เพื่อเปิดแบบ file:// — แต่การเข้าถึงกล้อง/ฟีเจอร์บางอย่างอาจถูกจำกัดโดยเบราว์เซอร์

2) แนะนำ: รันจาก localhost (กล้องจะทำงานได้เพราะ localhost ถือเป็น secure context)
- Python 3:
  - python3 -m http.server 8000
  - แล้วเปิด http://localhost:8000/index.html
- Node (http-server):
  - npx http-server -p 8000
  - หรือใช้ npx live-server
- VSCode: ใช้ extension "Live Server" เพื่อเปิดโฟลเดอร์และรัน

3) การใช้งานผ่าน HTTPS / โปรดทราบบน iOS:
- หากต้องการใช้กล้องบนอุปกรณ์ iOS/Safari หรือให้แน่ใจว่าเบราว์เซอร์ถือว่าเป็น secure context ให้เปิดผ่าน HTTPS หรือใช้โฮสต์ที่รองรับ HTTPS (เช่น GitHub Pages, Netlify, Vercel)
- localhost (http://localhost) จะทำงานกับกล้องบนเบราว์เซอร์เดสก์ท็อป แต่บน iOS/Safari ต้องใช้ HTTPS

4) Deployment (ตัวอย่าง)
- GitHub Pages: ตั้งค่าให้เสิร์ฟจาก branch `main` หรือ `gh-pages` (เลือก root `/` หรือโฟลเดอร์นี้เป็น root)
- หรือ Deploy บน Static host เช่น Netlify / Vercel — ลากโฟลเดอร์แล้วตั้งค่าให้เสิร์ฟไฟล์ `index.html`

## การตั้งค่าเบื้องต้นภายในแอป
- เปิด Settings (⚙️) ภายใน UI เพื่อกรอกข้อมูลร้าน, ตั้งค่า PIN, เบอร์ PromptPay, ข้อมูลผู้เสียภาษี ฯลฯ
- หากต้องการซิงค์กับ Supabase: กรอกค่าการเชื่อมต่อ (URL, anon key หรือการตั้งค่าที่แอปต้องการ) ผ่านหน้า Settings — (หมายเหตุ: เนื่องจากโค้ดเป็นไฟล์เดียว ให้ค้นหา/แก้ไขใน `index.html` ถ้าต้องการเปลี่ยนพฤติกรรมการเชื่อมต่อแบบถาวร)
- การอัพโหลดรูปภาพ/เอกสาร: แอปรองรับการอัปโหลด (จะส่งไปยัง Supabase หรือเก็บชั่วคราว ขึ้นกับการตั้งค่าในโค้ด)

## คำเตือน & ข้อจำกัดที่ควรทราบ
- กล้องสแกนบาร์โค้ดจะไม่ทำงานหากหน้าเว็บถูกโหลดจาก HTTP บนโดเมนที่ไม่ใช่ localhost — ต้องใช้ HTTPS หรือ localhost
- แอปปัจจุบันเก็บโค้ดทั้งหมดในไฟล์ `index.html` — ยากต่อการดูแลเมื่อโปรเจกต์เติบโต แนะนำแยกไฟล์ JS/CSS/HTML ในอนาคต
- ไม่มีไฟล์ LICENSE ในรีโป — หากต้องการให้ซอฟต์แวร์ใช้ได้ตามเงื่อนไขที่ชัดเจน ควรเพิ่มไฟล์ LICENSE (เช่น MIT)
- ข้อมูลสำคัญ (เช่น keys) หากถูกใส่ตรง ๆ ในไฟล์ HTML จะไม่ปลอดภัย — หากเชื่อมต่อ Supabase หรือบริการอื่น ให้ระมัดระวังการเผยแพร่คีย์สู่สาธารณะ

## การดีบั๊กทั่วไป
- กล้องไม่ทำงาน:
  - ตรวจสอบว่าอนุญาตใช้กล้องในเบราว์เซอร์แล้ว
  - เปิดจาก `http://localhost` หรือผ่าน HTTPS (iOS ต้อง HTTPS)
- สแกนแล้วไม่พบผลลัพธ์:
  - ตรวจสอบว่าโค้ดบาร์โค้ดรองรับประเภทนั้น (1D/2D) และแสงเพียงพอ
- ข้อมูลไม่ถูกบันทึก:
  - ตรวจสอบ console log (DevTools) — ถ้าเกิด error จะแสดงในกล่องแจ้งข้อผิดพลาดของหน้า (index.html มีระบบแสดงข้อผิดพลาดบนหน้าจอด้วย)
